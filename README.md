# Price Negotiating Chatbot for E-Commerce Website

An AI-based chatbot that lets customers negotiate product prices in real time on an e-commerce platform, suggesting optimal prices to both buyers and sellers.

## Overview
The chatbot analyzes user price negotiation inputs, applies negotiation rules and NLP-based logic, and returns fair, optimized price suggestions — automating a process that's normally manual and improving customer engagement on the platform.

## Tech Stack
- **Language:** Python
- **ML/AI:** TensorFlow, NumPy, NLP, CNN
- **Frontend:** HTML, CSS
- **Data:** CSV-based product & negotiation datasets

## Features
- User registration/login and browsing of products
- Real-time chat-based price negotiation with the bot
- Voice bot support
- Order viewing and product review system

## How to Run
1. Clone the repository
   ```bash
   git clone https://github.com/anil67-cmd/price-negotiating-chatbot-ecommerce.git
   cd price-negotiating-chatbot-ecommerce
   ```
2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application
   ```bash
   python Main.py
   ```
4. Open the app in your browser at the local address shown in the terminal
